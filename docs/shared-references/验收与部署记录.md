## 已复现并修复的缺陷

- 普通 Project/Agent 保存删除后重插：外键引用受损、旧保存可覆盖已发布容器。修复为带所有权边界的更新，删除和环境发布竞争回归先失败后通过。
- 候选容器已经写入绑定事务后被旧操作误删：增加当前绑定保护；旧的 superseded 操作仍会回收不再受保护的资源。发布后 exit 137 与新修订恢复实测通过。
- 停止并应用的取消被 Docker 并发队列延后：先持久化目标并立即取消已命名的当前 Turn，再进入有限并发换代；真实取消延迟断言通过。
- Agent 删除与恢复竞争丢失类型化 NotFound：保留删除终态，真实恢复/删除/应用竞争通过。
- SQLite 冷存储缺少工具任务完整结果回读：确定性回归先失败，再验证跨分页、重启及 Thread 隔离通过。
- Reviewer 克隆后用已改写的传输 URL 校验 origin，误拒绝 insteadOf 镜像：真实 Git 回归先失败，再改为读取持久 remote.origin.url 后通过；自动 Reviewer 冻结视图实机场景也已通过。
- 手机长源名撑宽控件，以及点击 References 页签带动整块页面横移：实际几何分别复现 503 px 控件超出 308 px 卡片、卡片左边界 -69 px；宽度与滚动边界分别修复，并纳入浏览器几何断言。
